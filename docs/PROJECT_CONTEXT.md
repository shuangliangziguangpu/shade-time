# 荫时 ShadeTime 项目上下文

依据：项目负责人于 2026-11-14 提供的 V1.0 接管档案和本地实查。本文是规格整理，不是完整原始 Prompt 导出，也不代表功能已实现。

## 目标与范围

面向校园户外活动组织者的 AI 三维遮阴实验与布置决策实验室。帮助用户理解太阳、参考高度和遮挡关系，用自然语言表达限制，比较有限候选布置，预览、确认、撤销和保存方案。以省赛一等奖为目标，不承诺获奖。

用户指定 GPT-6 Astra Max 为主力开发模型；用户负责产品决策、运行验收和竞赛提交。不得重新选题、扩大 MVP、伪造访谈、测试、AI 对话或开发历史。重要产品规则和技术路线变化须先向用户说明。

已冻结：一个目标区域、一个遮阳棚、固定基础几何、有限候选、解析式遮挡、三条受约束 AI 链。无通用编辑器，无建筑移动，无 React/Vue/Express/数据库/复杂 Agent 框架。

## 太阳和时间

大连城市级近似位置：38.914°N、121.614°E、Asia/Shanghai，非校园测绘数据。活动同日 15–120 分钟、输入步长5分钟、采样间隔15分钟，必须包含结束时刻，保留不足15分钟的末段。

锁定 SunCalc 1.9.0：输入经纬度为度，输出高度 h、方位 A 为弧度，A=0 南，-π/2 东，+π/2 西，±π 北。

从场景指向太阳：s=(-cos(h)sin(A), sin(h), cos(h)cos(A))。DirectionalLight 位于 C+Ls，目标 C，传播方向 -s。

h≤0：地平线以下，指标 N/A；0<h<5°：不支持正常分析；h≥5°：有效。5°是工程限制。SunCalc 高度不得标称为经大气折射修正的表观高度。任一必要时刻无效则整段正常平均值和推荐排名不可用。

## 计算与指标

Three.js 0.160.0 的 Ray.intersectBox 为事实计算，阴影贴图仅用于显示。遮挡白名单仅 B1、B2、棚顶、四根支柱；地面、参考面、文字和辅助线不参与。

区域 10×10 等面积格中心采样，固定分母100。点坐标：x=xc+((i+0.5)/10-0.5)w，z=zc+((j+0.5)/10-0.5)d。原点先检查是否在实体内或表面，若是则布局无效；否则由 p+10^-4 s 沿 s 检测正向交点。多次命中只计一次，记录最近命中对象作为遮挡见证，不代表唯一原因。不得删除异常点改变分母。

界面固定名称：当前采样点遮阴率、时段平均采样遮阴率、采样时刻最低遮阴率。S_k=遮挡点数/100；时段平均为按时间间隔加权的梯形近似；最低为采样时刻最小值。不是连续真实面积或整段遮阴保证，不推算温度、紫外线、健康安全或完整人体状态。

排序：采样最低值降序 → 未舍入平均值降序 → 移动物体数升序 → 固定 ID。最优仅限当前候选、约束、采样与排序设置。

## 架构和 AI 边界

原生 ES Modules、Node 内置 HTTP、node:test、LocalStorage、JSON、Git/GitHub。浏览器与 Node 复用核心数学代码。模块职责：启动/UI、三维视图、领域状态、太阳、分析、AI 协议、服务端、保存。

计算链：合法状态 → 太阳方向 → 几何分析 → 指标证据 → 显示。
AI 链：用户文本/状态 → 服务端权威重算 → 模型 → 严格协议校验 → 候选重算 → 预览 → 用户确认。

三条链：
1. 空间解释：绑定选中对象、时间、参考高度、太阳方向、采样、遮挡物和当前版本证据 ID；可定位证据。
2. 约束理解：草案仅包含区域/棚是否可动、最低遮阴目标等已支持字段，校验后由用户确认；模糊或不支持需求须澄清，不可删除硬约束。
3. 建议验证：只能选本次合法候选 ID；校验权限、位置、版本并重算比较，用户预览确认后应用，可拒绝撤销。

结果区分：无合格候选、无改善、有取舍的改善、状态过期。有限候选无解不等于现实绝对无解。

禁止任意坐标操作、建筑移动、直接改场景、执行代码、eval、伪造指标；严格 JSON，未知字段拒绝。API Key 仅服务端环境变量，不进前端/日志/截图/保存/Git。供应商和模型由服务端固定，客户端不能传目标 URL；超时20秒；限制体积、文本、历史和频率；文本使用纯文本输出。供应商尚未确定，不复用旧项目配置。

业务变更递增版本，撤销也递增，保留最近10次快照；相机不改变业务版本。时间、选中对象及解释上下文变化使相关请求失效。请求记录 requestId/baseVersion/sceneVersion/analysisId，拒绝过期和逆序结果。

保存包含格式/场景版本、候选 ID、日期时段时区、已确认约束、算法与采样版本。可保存指标快照，但导入后必须重算。非法/未知版本拒绝，LocalStorage 不可用时提示。
