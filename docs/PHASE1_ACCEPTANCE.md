## 2 几何与业务规则

### 统一坐标

单位米，+X东、+Y上、+Z南、-Z北。庭院X[-12,12]、Z[-9,9]、Y=0；B1为X[-12,-8]、Y[0,6]、Z[-9,9]；B2为X[2,10]、Y[0,4]、Z[6,9]。通道X[-1,1]、Z[-9,6]不可占用。

| 位置ID | (X,Z) | 目标区域 | 棚候选 |
| --- | --- | --- | --- |
| R1 | (-5,-2) | 可用 | 是 |
| R2 | (0,-2) | 通道拒绝 | 否 |
| R3 | (5,-2) | 可用 | 是 |
| R4 | (-5,3) | 可用 | 是 |
| R5 | (0,3) | 通道拒绝 | 否 |
| R6 | (5,3) | 可用 | 是 |

目标区域始终为2×2米。一个布局只有一个实际棚，七个遮挡实体为B1、B2、C_ROOF、C_POST_NW/SW/NE/SE。四个棚候选中心使用同一TD004工厂生成；当前棚实心显示，其余三个以线框展示，不投影、不加入遮挡列表。六处区域均显示，但非法位置不能应用。

### TD004 已批准并实际实现

棚顶3×3米，Y[2.4,2.5]；四柱0.1×0.1米，Y[0,2.4]，柱中心相对棚中心X/Z各±1.45米，外侧齐平、顶部连接。四处候选均验证尺寸/连接；另有实际射线分别命中棚柱和棚顶的测试。

### TD006 本轮澄清后冻结

原文没有明确1厘米距离度量，实施相应模块前向用户提问。用户确认XZ俯视矩形间最短欧氏距离，包含斜对角；恰好0.010米合格，接触和重叠不合格。区域和棚距庭院边界也至少0.010米。构件正常连接豁免。

区域检查建筑、通道及实际柱占地；棚占地检查建筑与通道。目标位于棚顶投影下允许。数值比较仅补偿坐标尺度8个机器epsilon的十进制相减舍入误差（本庭院约10^-14米量级），不修改1厘米规则或原射线1e-4米偏移。0/0.009/0.010/0.011米及小于阈值1e-10米的用例均按预期通过。

## 3 计算与渲染一致性

同一场景描述派生分析Box3和Three网格，实体尺寸、中心和ID逐项检查。四个实际棚位均验证七个网格的世界包围盒，容许BoxGeometry的Float32顶点表示误差小于1e-7米；分析仍使用原双精度射线，不降低精度。地面、通道与六个候选区域的平面尺寸/中心也经过检查。

根据庭院和建筑联合包围球确定光源距离与阴影相机，不沿用小夹具±5范围或12米距离。12组人工太阳方向（5/45/75°高度×四方位）下，完整包围盒均处于阴影相机范围内。太阳方向公式及光照传播方向没有更改。

七个实体以外的候选轮廓、参考面、叠加采样点、箭头、文字和辅助线不参与射线计算，也不投射实体阴影。叠加点和参考面的微小显示抬升只是显示处理；计算点仍为Y=0或Y=1.5。阴影贴图没有参与任何比例计算。
