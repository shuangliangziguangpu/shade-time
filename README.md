# 荫时（ShadeTime）

英文名称：ShadeTime。

项目定位：AI 三维遮阴实验与布置决策实验室。

## 项目目标

帮助用户通过 AI 引导的三维实验，理解太阳位置、空间遮挡和不同时间的阴影变化，探索户外活动区域的遮阴布置方案。

## 计划中的核心功能

以下功能均为开发计划，当前尚未实现：

- 按日期与时段探索太阳方向和三维场景中的阴影变化。
- 比较地面与人员参考高度的几何遮挡结果，并展示空间证据。
- 通过自然语言表达目标与约束，由 AI 解释空间现象。
- 对有限候选布置进行几何计算与约束检查，预览和验证 AI 建议。
- 应用或撤销布置调整，保存和恢复实验方案。

## 计划采用的技术方向

- Three.js：三维场景与交互。
- SunCalc：太阳位置计算。
- JavaScript：场景状态、几何遮挡分析和用户交互。
- Node.js：本地服务与后续 AI 请求代理。
- 大语言模型 API：自然语言交互、约束理解和空间解释。
- Git / GitHub：版本管理与真实开发过程记录。

当前构想采用构造实验场景。未来计算结果仅用于理解该简化模型内的太阳方向与直射光遮挡，不代表真实建筑评估、专业日照分析或专业防晒评估，也不能直接推算温度、紫外线剂量或人体健康风险。
